# Personal Portfolio Website

A simple personal portfolio website created using **HTML and basic CSS** to showcase my profile and provide contact information.

## Pages

- **Home Page:** Introduces me and provides a basic overview of my portfolio.
- **Contact Page:** Displays contact information so visitors can get in touch with me.

## Technologies Used

- HTML5
- CSS3

## Features

- Simple and clean design
- Easy navigation between Home and Contact pages
- Beginner-friendly web development project

## Purpose

This project was developed to practice my HTML and CSS skills and build a foundation in front-end web development.
